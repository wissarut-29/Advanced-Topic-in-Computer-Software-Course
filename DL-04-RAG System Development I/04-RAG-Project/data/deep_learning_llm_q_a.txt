Q: Deep Learning คืออะไร และแตกต่างจาก Machine Learning อย่างไร
A: Deep Learning เป็นสาขาย่อยของ Machine Learning ที่ใช้โครงข่ายประสาทเทียมหลายชั้น (Deep Neural Networks) ในการเรียนรู้ลักษณะเด่น (features) จากข้อมูลดิบโดยอัตโนมัติ ในขณะที่ Machine Learning แบบดั้งเดิมมักต้องการการออกแบบลักษณะเด่นโดยผู้เชี่ยวชาญ (Feature Engineering) ตัวอย่างเช่น ในการแยกแยะภาพรถยนต์ Machine Learning ทั่วไปต้องให้คนระบุขอบและรูปร่างก่อนส่งให้โมเดล แต่ Deep Learning สามารถเรียนรู้จุด ขอบ รูปร่าง และลักษณะเฉพาะของรถยนต์ได้เองจากภาพตัวอย่างจำนวนมาก

[หมวด: โครงข่ายประสาทเทียมและดีปเลิร์นนิง]
Q: Activation Function คืออะไร และทำไมต้องใช้ในโครงข่ายประสาทเทียม
A: Activation Function (ฟังก์ชันกระตุ้น) คือฟังก์ชันทางคณิตศาสตร์ที่คำนวณเอาต์พุตของโหนดในโครงข่ายประสาทจากผลรวมถ่วงน้ำหนักของอินพุต เหตุผลที่ต้องใช้เนื่องจากช่วยเพิ่มคุณสมบัติที่ไม่เป็นเส้นตรง (Non-linearity) ให้กับโมเดล ทำให้โครงข่ายประสาทสามารถเรียนรู้และแก้ปัญหาที่มีความซับซ้อนและไม่เป็นเส้นตรงได้ หากไม่มีฟังก์ชันกระตุ้น โครงข่ายประสาททั้งหมดจะทำงานเหมือนสมการเชิงเส้นเส้นเดียว ไม่ว่าจะซ้อนกันกี่ชั้นก็ตาม ตัวอย่างฟังก์ชันที่นิยม ได้แก่ ReLU, Sigmoid, และ Tanh

[หมวด: โครงข่ายประสาทเทียมและดีปเลิร์นนิง]
Q: Backpropagation คืออะไรและมีบทบาทอย่างไรในการเทรนโมเดล
A: Backpropagation (การแพร่ย้อนกลับ) คือกระบวนการคำนวณเกรเดียนต์ (Gradient) ของฟังก์ชันความสูญเสีย (Loss Function) เทียบกับน้ำหนัก (Weights) ทั้งหมดในโครงข่ายประสาทจากเลเยอร์สุดท้ายย้อนกลับไปเลเยอร์แรก โดยอาศัยกฎลูกโซ่ (Chain Rule) ข้อมูลเกรเดียนต์นี้จะถูกนำไปใช้โดย Optimizer (เช่น SGD, Adam) เพื่อปรับปรุงค่าน้ำหนักให้โมเดลมีความผิดพลาดน้อยลงในรอบถัดไป ถือเป็นหัวใจสำคัญของการเรียนรู้ใน Deep Learning

[หมวด: โครงข่ายประสาทเทียมและดีปเลิร์นนิง]
Q: Overfitting ใน Deep Learning คืออะไร และมีวิธีแก้ไขอย่างไร
A: Overfitting คือสถานการณ์ที่โมเดลเรียนรู้รายละเอียดและสัญญาณรบกวน (Noise) ในข้อมูลที่ใช้ฝึกฝนมากเกินไป จนทำให้ประสิทธิภาพดีมากในฐานข้อมูลฝึกฝน (Train set) แต่เมื่อนำไปทดสอบกับข้อมูลใหม่ที่โมเดลไม่เคยเห็น (Validation/Test set) กลับได้ผลลัพธ์ที่แย่ วิธีแก้ไข ได้แก่ การเพิ่มข้อมูลฝึกฝน การใช้ Regularization (เช่น L1/L2), การทำ Dropout (สุ่มปิดโหนดบางตัวระหว่างเทรน), การหยุดเทรนก่อนกำหนด (Early Stopping), และการลดความซับซ้อนของโครงข่าย

[หมวด: โครงข่ายประสาทเทียมและดีปเลิร์นนิง]
Q: Loss Function คืออะไร และมีความแตกต่างกันอย่างไรตามประเภทงาน
A: Loss Function (ฟังก์ชันความสูญเสีย) คือตัววัดเพื่อประเมินว่าการทำนายของโมเดลห่างไกลจากความจริงมากเพียงใด ยิ่งค่าน้อยลงแสดงว่าโมเดลทำนายได้แม่นยำขึ้น การเลือกใช้งานขึ้นอยู่กับโจทย์ เช่น งานถดถอย (Regression) มักใช้ Mean Squared Error (MSE) หรือ Mean Absolute Error (MAE) ส่วนงานจำแนกประเภท (Classification) มักใช้ Binary Cross-Entropy สำหรับผลลัพธ์ 2 ประเภท และ Categorical Cross-Entropy สำหรับผลลัพธ์หลายประเภท

[หมวด: ทรานส์ฟอร์เมอร์และการประมวลผลภาษา]
Q: สถาปัตยกรรม Transformer คืออะไร และทำไมจึงปูทางสู่ยุคปัจจุบัน
A: Transformer เป็นสถาปัตยกรรมโครงข่ายประสาทเทียมที่พัฒนาโดย Google ในปี 2017 ออกแบบมาเพื่อจัดการข้อมูลลำดับ (Sequential Data) เช่น ข้อความ โดยใช้กลไกการดึงความสนใจในตัวเอง (Self-Attention Mechanism) แทนการใช้โครงสร้างแบบวนซ้ำ (RNN/LSTM) ทำให้สามารถประมวลผลคำทั้งหมดในประโยคได้พร้อมกันแบบขนาน (Parallel Processing) ลดข้อจำกัดในการประมวลผลประโยคยาวๆ และเพิ่มประสิทธิภาพในการประมวลผลบน GPU อย่างก้าวกระโดด

[หมวด: ทรานส์ฟอร์เมอร์และการประมวลผลภาษา]
Q: Self-Attention Mechanism ใน Transformer ทำงานอย่างไร
A: Self-Attention เป็นกลไกที่ช่วยให้โมเดลประเมินความเกี่ยวข้องระหว่างคำต่าง ๆ ในประโยคเดียวกันได้ โดยโมเดลจะคำนวณค่าเวกเตอร์สามตัวสำหรับแต่ละคำ ได้แก่ Query (Q), Key (K), และ Value (V) จากนั้นจะทำ Dot-product ระหว่าง Q และ K เพื่อหาคะแนนความเชื่อมโยง นำคะแนนที่ได้ไปผ่าน Softmax แล้วคูณกับเวกเตอร์ V ผลลัพธ์ที่ได้ทำให้โมเดลเข้าใจความหมายของคำบริบทนั้น ๆ ได้ดี เช่น คำว่า "ธนาคาร" ในประโยค "เดินไปธนาคารเพื่อถอนเงิน" จะถูกดึงความสนใจเชื่อมกับคำว่า "ถอนเงิน" มากกว่าคำว่า "เดิน"

[หมวด: ทรานส์ฟอร์เมอร์และการประมวลผลภาษา]
Q: BERT และ GPT แตกต่างกันอย่างไรในเชิงโครงสร้างและการใช้งาน
A: ทั้งสองรุ่นใช้ฐานสถาปัตยกรรม Transformer แต่จุดเน้นและการเชื่อมโครงสร้างต่างกัน โดย BERT (Bidirectional Encoder Representations from Transformers) ใช้ฝั่ง Encoder เน้นอ่านข้อความสองทิศทางพร้อมกัน เหมาะกับงานเข้าใจภาษา (NLU) เช่น การจำแนกคำถาม ค้นหาคำตอบ และจับคู่อารมณ์ ส่วน GPT (Generative Pre-trained Transformer) ใช้ฝั่ง Decoder เน้นอ่านและทำนายคำถัดไปทีละคำจากซ้ายไปขวา เหมาะกับงานสร้างสรรค์ข้อความ (NLG) เช่น การเขียนบทความ และการสนทนาโต้ตอบ

[หมวด: ทรานส์ฟอร์เมอร์และการประมวลผลภาษา]
Q: Tokenization ใน NLP คืออะไร และทำไมต้องใช้ Byte Pair Encoding (BPE)
A: Tokenization คือกระบวนการแบ่งข้อความหรือประโยคให้เป็นหน่วยย่อยที่สุดที่เรียกว่า Token (เช่น คำ คำย่อย หรือตัวอักษร) เพื่อส่งให้โมเดลประมวลผล ส่วน Byte Pair Encoding (BPE) เป็นเทคนิคการทำ Subword Tokenization ที่รวมคู่อักขระที่พบบ่อยเข้าด้วยกัน ช่วยแก้ปัญหาคำนอกพจนานุกรม (Out-of-Vocabulary หรือ OOV) และลดขนาดพจนานุกรมคำลง ทำให้โมเดลสามารถจัดการกับคำสะกดผิด หรือคำประสมใหม่ๆ ได้อย่างมีประสิทธิภาพ

[หมวด: โมเดลภาษาขนาดใหญ่]
Q: Large Language Model (LLM) คืออะไร และเรียนรู้อย่างไร
A: Large Language Model (LLM) คือโมเดลภาษาที่ใช้โครงสร้างเครือข่ายลึกขนาดใหญ่ (พารามิเตอร์หลักพันล้านถึงแสนล้านตัว) ฝึกฝนด้วยข้อมูลตัวอักษรมหาศาลจากอินเทอร์เน็ต การเรียนรู้หลักๆ แบ่งเป็น 2 ขั้นตอนคือ 1) Pre-training เป็นการเรียนรู้แบบไม่มีผู้สอนเพื่อทำนายคำถัดไป (Next-token prediction) ทำให้โมเดลมีความรู้รอบตัวและโครงสร้างภาษา และ 2) Fine-tuning (มักใช้วิธี RLHF หรือ Instruction Tuning) เพื่อปรับการตอบสนองให้เหมาะสมและปลอดภัยตามคำสั่งมนุษย์

[หมวด: โมเดลภาษาขนาดใหญ่]
Q: Parameter ใน LLM คืออะไร และการเพิ่มขึ้นส่งผลอย่างไร
A: Parameter (พารามิเตอร์) ในโมเดลภาษาขนาดใหญ่คือค่าน้ำหนัก (Weights) และค่าเอนเอียง (Biases) ที่โมเดลเรียนรู้และปรับแต่งในระหว่างการฝึกฝนเพื่อประมวลผลและทำนายคำ การเพิ่มจำนวนพารามิเตอร์ทำให้โมเดลมีความจุทางความรู้และความเข้าใจไวยากรณ์ที่ซับซ้อนมากขึ้น ส่งผลให้เกิดความสามารถที่ฉุกเฉินขึ้นมาเอง (Emergent Abilities) เช่น การใช้เหตุผล แต่ก็แลกมาด้วยต้นทุนการคำนวณ ความต้องการหน่วยความจำ (VRAM) และระยะเวลาในการประมวลผลที่สูงขึ้นอย่างมาก

[หมวด: โมเดลภาษาขนาดใหญ่]
Q: RLHF (Reinforcement Learning from Human Feedback) คืออะไร
A: RLHF คือกระบวนการฝึกฝนขั้นสุดท้ายของ LLM เพื่อจัดตำแหน่ง (Alignment) โมเดลให้ตอบคำถามได้ตรงใจ ปลอดภัย และมีประโยชน์ต่อมนุษย์ โดยขั้นแรกจะให้ผู้เชี่ยวชาญมนุษย์ประเมินและจัดอันดับผลการตอบของโมเดลในหลายๆ รูปแบบเพื่อนำไปสร้าง Reward Model (โมเดลรางวัล) จากนั้นจะใช้ Reward Model นี้เป็นฟังก์ชันให้คะแนนในการฝึกฝนโมเดลหลักผ่านการเรียนรู้แบบเสริมกำลัง (Reinforcement Learning) เช่น อัลกอริทึม PPO

[หมวด: โมเดลภาษาขนาดใหญ่]
Q: Hallucination ใน LLM คืออะไร และมีสาเหตุจากอะไร
A: Hallucination (การประสาทหลอนของแบบจำลอง) คือเหตุการณ์ที่โมเดล LLM สร้างคำตอบที่ดูสมเหตุสมผลและมีความมั่นใจสูง แต่ข้อมูลในคำตอบนั้นผิดความจริง ไม่มีหลักฐานอ้างอิง หรือไม่เกี่ยวข้องกับอินพุต สาเหตุเกิดจากข้อมูลฝึกฝนมีข้อบกพร่อง การที่โมเดลพยายามทำนายคำถัดไปตามสถิติของภาษาโดยไม่มีแนวคิดเรื่องความจริงแท้จริง หรือข้อจำกัดด้านความจุของหน่วยความจำของพารามิเตอร์

[หมวด: โมเดลภาษาขนาดใหญ่]
Q: Temperature ในการสร้างข้อความของ LLM มีหน้าที่อะไร
A: Temperature (อุณหภูมิ) คือไฮเปอร์พารามิเตอร์ที่ควบคุมระดับความสร้างสรรค์หรือความสุ่มของข้อความที่โมเดลสร้างขึ้น โดยส่งผลต่อการคำนวณ Softmax ของโอกาสในการเลือกคำถัดไป ค่า Temperature ต่ำ (ใกล้ 0) จะทำให้โมเดลเลือกเฉพาะคำที่น่าจะเป็นไปได้มากที่สุด ส่งผลให้ตอบคำถามเดิมซ้ำๆ และเน้นข้อเท็จจริง ส่วนค่า Temperature สูง (ใกล้ 1 หรือมากกว่า) จะเพิ่มความหลากหลายของคำตอบ เหมาะกับงานแต่งเรื่องหรืองานสร้างสรรค์

[หมวด: ระบบสืบค้นข้อความและการทำ RAG]
Q: RAG (Retrieval-Augmented Generation) คืออะไร และแก้ปัญหาอะไรของ LLM
A: RAG คือสถาปัตยกรรมที่รวมกระบวนการสืบค้นข้อมูลภายนอก (Retrieval) เข้ากับกระบวนการสร้างข้อความของ LLM (Generation) โดยแทนที่จะให้ LLM ตอบจากหน่วยความจำพารามิเตอร์โดยตรง ระบบจะไปค้นหาเอกสารหรือข้อความที่เกี่ยวข้องในฐานข้อมูลความรู้ภายนอกก่อน แล้วนำข้อมูลเหล่านั้นมาแนบไปกับพรอมต์ส่งให้ LLM ตอบ วิธีนี้ช่วยแก้ปัญหาเรื่องข้อมูลที่ล้าสมัย (LLM ค้นหาข้อมูลเรียลไทม์ได้) และลดปัญหา Hallucination เพราะมีเอกสารอ้างอิงประกอบ

Q: Vector Database คืออะไร และสำคัญอย่างไรต่อระบบ RAG
A: Vector Database คือฐานข้อมูลที่ออกแบบมาเพื่อจัดเก็บ ค้นหา และจัดการข้อมูลในรูปแบบเวกเตอร์ความหนาแน่นสูง (Dense Vectors) ซึ่งแปลงมาจากข้อมูลประเภทต่างๆ เช่น ข้อความ ภาพ หรือเสียง ผ่านโมเดล Embedding ความสำคัญของมันในระบบ RAG คือช่วยให้เราค้นหาข้อมูลเชิงความหมาย (Semantic Search) ได้อย่างรวดเร็ว ผ่านการคำนวณหาระยะห่างของเวกเตอร์ (Vector Distance) เช่น Cosine Similarity ทำให้พบข้อมูลที่เกี่ยวข้องกันแม้จะไม่ใช้คำสำคัญพ้องกัน (Keywords) ตรงๆ ก็ตาม

Q: ข้อดีและข้อเสียของการค้นหาด้วย Vector Search เทียบกับ Keyword Search (BM25) คืออะไร
A: Vector Search ค้นหาเชิงความหมายได้เข้าใจบริบท ค้นหาคำพ้องความหมายได้ดี แต่ต้องใช้แรงประมวลผลสูงและทำงานช้ากว่าหากไม่มีดัชนีเฉพาะทางที่ดี ส่วน Keyword Search (เช่น BM25) ทำงานได้รวดเร็วมาก ค้นหาชื่อเฉพาะหรือรหัสตัวเลขเฉพาะเจาะจงได้แม่นยำกว่า แต่ไม่เข้าใจความหมายแฝง ในทางปฏิบัติระบบ RAG สมัยใหม่จึงนิยมใช้ Hybrid Search ที่ผสานรวมคะแนนการสืบค้นของทั้งสองวิธีเพื่อผลลัพธ์ที่ดีที่สุด

Q: Chunking คืออะไร และทำไมจึงจำเป็นต้องเลือกขนาด Chunk ให้เหมาะสม
A: Chunking คือกระบวนการแบ่งข้อความหรือเอกสารขนาดยาวออกเป็นชิ้นย่อยๆ (Chunks) ก่อนนำไปแปลงเป็นเวกเตอร์และเก็บลงฐานข้อมูล ความจำเป็นในการระบุขนาด Chunk ให้พอดีเพราะ 1) หาก Chunk ใหญ่เกินไป เวกเตอร์ผลลัพธ์อาจสูญเสียรายละเอียดเฉพาะตัว และอาจทำให้ข้อมูลที่ส่งเข้าบริบทของ LLM เกินขีดจำกัดหน้าต่าง (Context Window) 2) หาก Chunk เล็กเกินไป ข้อมูลที่ค้นพบอาจขาดบริบทโดยรอบจนทำให้คำถามที่ตอบมีความหมายไม่ครบถ้วน

Q: Cosine Similarity คืออะไร และมีบทบาทอย่างไรในการสืบค้นข้อมูล
A: Cosine Similarity คือเมตริกวัดความคล้ายคลึงกันระหว่างเวกเตอร์สองตัว โดยวัดขนาดของมุมระหว่างเวกเตอร์เหล่านั้นในปริภูมิหลายมิติ มีค่าระหว่าง -1 ถึง 1 (หรือ 0 ถึง 1 สำหรับเวกเตอร์ Embedding ของข้อความทั่วไป) ค่ายิ่งใกล้ 1 แสดงว่าเวกเตอร์ทั้งสองชี้ไปในทิศทางเดียวกันและมีความคล้ายคลึงเชิงความหมายสูง ใน RAG เราใช้ค่านี้เพื่อจัดอันดับเอกสารที่เกี่ยวข้องกับคำถามของผู้ใช้มากที่สุด

Q: Fine-tuning กับ RAG ต่างกันอย่างไรและควรเลือกใช้เมื่อไร
A: RAG เปรียบเหมือนการสอบแบบเปิดตำรา (Open-book) ส่วน Fine-tuning เปรียบเหมือนการเรียนจบหลักสูตรเพื่อจดจำความรู้ (Closed-book) ควรเลือก RAG เมื่อข้อมูลมีการเปลี่ยนแปลงบ่อย มีขนาดใหญ่ และต้องการการอ้างอิงแหล่งที่มาที่ชัดเจน ส่วน Fine-tuning เหมาะเมื่อต้องการเปลี่ยนรูปแบบการตอบสนองของโมเดล (Tone of voice) ให้ทำงานเฉพาะทางที่ซับซ้อน หรือต้องการสอนศัพท์และพฤติกรรมเฉพาะอุตสาหกรรมที่โมเดลฐานไม่รู้จักเลย

Q: PEFT (Parameter-Efficient Fine-Tuning) คืออะไร และ LoRA ทำงานอย่างไร
A: PEFT คือชุดเทคนิคในการทำ Fine-tuning โมเดลขนาดใหญ่โดยการปรับแต่งค่าน้ำหนักเพียงส่วนน้อยเพื่อประหยัดทรัพยากรการคำนวณ ส่วน LoRA (Low-Rank Adaptation) ทำงานโดยการล็อกค่าน้ำหนักเดิมของโมเดลไว้ แล้วใช้วิธีแทรกเมทริกซ์ย่อยขนาดเล็ก (Low-rank matrices) สองตัวเข้าไปขนานกับเลเยอร์เดิมเพื่อเรียนรู้เฉพาะส่วนต่าง ทำให้น้ำหนักที่ปรับแต่งมีขนาดเล็กลงมาก ช่วยลดการใช้ VRAM และพื้นที่จัดเก็บได้อย่างมหาศาล

Q: Prompt Engineering คืออะไร และเทคนิค Few-shot Prompting คืออะไร
A: Prompt Engineering คือศาสตร์และศิลป์ในการออกแบบและปรับแต่งข้อความคำสั่ง (Prompts) เพื่อนำทางให้โมเดลภาษาขนาดใหญ่สร้างผลลัพธ์ที่ดีและแม่นยำที่สุด เทคนิค Few-shot Prompting คือการป้อนคำถามตัวอย่างและคำตอบที่ถูกต้องจำนวน 2-3 ตัวอย่างให้โมเดลดูก่อนในพรอมต์ เพื่อเป็นต้นแบบให้โมเดลเข้าใจโครงสร้าง รูปแบบ และแนวทางการตอบที่ต้องการก่อนที่จะตอบคำถามจริงของผู้ใช้
